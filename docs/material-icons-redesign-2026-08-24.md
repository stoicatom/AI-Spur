## 二、设计原则（基于icon-design skill）

### 2.1 核心原则
1. **Clarity over cleverness** - 含义必须即刻理解
2. **Consistency creates a visual language** - 整套素材视觉统一
3. **Optical alignment trumps mathematical precision** - 光学平衡优于数学精确
4. **Design for the smallest size first** - 从最小尺寸开始设计
5. **Simplicity scales; complexity fails** - 简洁可缩放，复杂会失败

### 2.2 Apple风格特征
基于SF Symbols设计语言：
- **统一笔触宽度**：6-8px主笔触，2-4px细节线
- **圆角处理**：统一的圆角半径（4-6px）
- **渐变使用克制**：优先纯色+高光，避免过度渐变
- **深度暗示**：通过光影而非立体感
- **留白呼吸感**：图形与边界保持充足间距
- **可读性优先**：即使在小尺寸也清晰可辨

### 2.3 尺寸要求
- **设计尺寸**：512×512px
- **安全区域**：距边界48px（内容区416×416px）
- **笔触基准**：主体6-8px，细节3-4px，装饰1-2px
- **最小测试**：需保证32×32px可识别

## 四、特效系统增强方案

### 4.1 分阶段叙事动画

**当前问题**：所有素材的crack特效都是单一爆发
**改进方向**：引入时间轴分段

```typescript
interface CrackStyleEnhanced extends CrackStyle {
  phases?: Phase[];
}

interface Phase {
  startTime: number;  // 0-1
  duration: number;   // 0-1
  sprite: SpriteTransform;
  emit: ParticleEmitter;
}
```

**示例：revolver（左轮手枪）**
```typescript
{
  phases: [
    { // 阶段1: 枪口火焰 (0-0.2s)
      startTime: 0,
      duration: 0.2,
      sprite: (t) => ({ dx: 0, dy: 0, scale: 1, rot: 0, alpha: 1 }),
      emit: (cx, cy) => P.flare(cx + 60, cy, 20, {...})
    },
    { // 阶段2: 子弹飞行 (0.2-0.6s)
      startTime: 0.2,
      duration: 0.4,
      sprite: (t) => ({ dx: t * 400, dy: 0, scale: 1, rot: 0, alpha: 1 }),
      emit: (cx, cy) => P.beam(cx, cy, cx + 400, cy, {...})
    },
    { // 阶段3: 远端爆炸 (0.6-1.0s)
      startTime: 0.6,
      duration: 0.4,
      sprite: (t) => ({ dx: 400, dy: 0, scale: 1, rot: 0, alpha: 1 - t }),
      emit: (cx, cy) => P.burst(cx + 400, cy, 30, {...})
    }
  ]
}
```

### 4.2 新粒子类型

需要在 `particles-emitters-extended.ts` 中添加：

1. **scaleParticles**：鳞片粒子（神龙）
2. **featherParticles**：羽毛粒子（凤凰）
3. **bulletTrail**：子弹轨迹（左轮手枪）
4. **vortexSuction**：漩涡吸入（黑洞）
5. **heatWave**：热浪扭曲（烈日）

### 4.3 聚焦素材本身的特效

**反例（当前问题）**：
```typescript
// 全屏背景光芒 - 与素材本身无关
P.burst(cx, cy, 100, 10, 20, { spread: 360 })
```

**正例（改进方向）**：
```typescript
// 从素材关键部位发射特定粒子
// 例：神龙的龙爪发射能量爪痕
P.clawSlash(
  cx + dragonClawOffsetX,
  cy + dragonClawOffsetY,
  direction,
  { hue: MATERIAL_HUE.dragon }
)
```
