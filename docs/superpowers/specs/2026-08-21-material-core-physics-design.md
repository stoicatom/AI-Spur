# 素材核心物理特效增强设计

## 目标

增强素材核心的可感知物理表现，保持每个素材由独立物理身份驱动。雷电从局部固定分支改为受惯性与空气阻力影响的跨屏闪电滑空；暴雨改为覆盖整个视口的高密度三层飘雨，并让 WebGL 与 Canvas 回退使用同一确定性雨场。

## 设计

- 雷电主链以固定 60 Hz 语义计算滑空位移，使用发射速度、加速度和指数阻尼得到沿素材方向的跨屏位移。分支、核心节点、冲击光晕和冲击球共享主链的 strike point，因此视觉核心不会停留在固定位置。
- 雷电主链半径、核心节点、冲击光晕和冲击球由能量、冲量和当前速度共同驱动，尺寸变化对应电荷释放和速度变化，而不是随机缩放。
- 暴雨共享 `downpour-field` 生成三层确定性雨滴。提高每层粒子预算，前景层拥有更长雨丝；风偏作为水平速度叠加在重力下落速度上。落地喷溅、地面雾和 Canvas 绘制继续复用同一场配置。
- 保留雨滴与用户挥动方向无关的契约，避免暴雨被误解为单次挥动轨迹。

## 验证

- 单元测试测量雷电主链跨时间的方向位移、核心/光晕/冲击尺寸，以及暴雨层密度、雨丝长度、风偏、全宽覆盖和 Canvas 绘制量。
- 完成后运行 Vitest、TypeScript 检查、Rust 测试与 clippy、生产构建，并执行现有桌面和窄屏 WebGL 非空像素检查。
