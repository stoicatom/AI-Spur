# 素材库 CG 级特效与图标统一设计（v1）

> 状态：设计稿（待审批）
> 日期：2026-08-28
> 上游：`2026-08-22-img2three-cinematic-upgrade-design.md`（hero 层增强，已实现）之上的全量 CG 级重建
> 关联目录：`docs/adr/`（选型 ADR，随 M0 写入）

## 0. 背景与目标

AISpur 素材库（v3 唯一选择轴：图标 + 特效 + 声音 + 配色）当前 42 个内置素材包，每个素材已有一个专属 Three.js 程序化特效场景（`three-family-*`，五大族分派），但实现为"基础几何近似"：闪电为圆柱折线段、黑洞为 torus 环 + 尘埃、爆炸为 icosahedron 火球 + 线框壳。视觉上可用，但与"3D 动漫 CG 级"存在明显差距。

本轮目标（用户确认）：

1. 侧边栏菜单"素材包"改名"素材库"。
2. 42 枚内置素材图标建立统一设计系统并全部重绘。
3. **42 个素材全部**逐素材设计 CG 级特效：物理特性、运动复杂度、趣味性、元素多样性、多元素互动、全屏性、视觉逼真性。
4. 特效必须达到 3D CG / 动漫电影级别的视觉效果。
5. 使用专业第三方 3D 库完成，禁止自研引擎。
6. **不限制应用体积**（打包体积 ≤ 15MB 性能预算相应调整）。
7. **不设固定 fps 下限**，以"最流畅"为准；性能与特效兼容性为核心验收指标。
8. 保证原功能不受影响：渲染 WebGL 失败自动降 2D canvas 的链路、声音、宏发送、Tauri 窗口生命周期全部不动。

## 1. 现状审计（事实基线）

| 项 | 现状 |
|---|---|
| 素材数量 | **42 个内置素材包**（`src-tauri/packs/<id>/`，含 `icon.svg` + `pack.json`）。`src-tauri/materials/`（52 个）为 v2 遗留目录，不在运行路径，本轮不触碰。 |
| 特效预设 | 42 个 `EffectPresetId`，每个内置素材恰好映射一个（如 black-hole→singularity、bomb→explode、glass-shot→glass-break、lightning→bolt、ice→shatter-ice、fireworks→fireworks），另有 6 个 legacy 预设（spiral/split/chain/twinkle/vortex/rain）仅服务旧用户包。 |
| 3D 底层 | `three@0.185`：`WebGLRenderer`（alpha/antialias/high-performance）+ `EffectComposer`（RenderPass + UnrealBloom 0.72/0.55/0.78 + OutputPass）+ ACES tone mapping + PMREM RoomEnvironment。正交相机 -w/2..w/2。 |
| 场景层 | `CinematicLayers` 按 `profile.family` 分派五大族（cosmic/impact/natural/rhythm/weapon），另挂 `FullFieldSpectacleLayer` 全屏场 + `three-image-hero` hero 层。 |

| 时长 | 基础特效时长 1200ms，12 个 preset 有覆盖（tornado 1800 / downpour 1900 / fireworks 1950 / singularity 1850 / glass-break 1550 等），`effect-timings.ts` 为 2D/WebGL/音频共享时间轴。 |

## 2. 技术选型（专业三方库，禁自研）

保留 `three` 为引擎底层（它就是业界标准专业 3D 库），其上叠加专业特效栈：

| 库 | 版本（实现期钉版） | 用途 | 选型理由 |
|---|---|---|---|
| `three` | 0.185（现有，升级至 0.185.x 最新） | 渲染引擎 | 不动 |
| `three.quarks`（@querielo/three.quarks） | ^0.17 | **GPU 粒子引擎**：火焰、烟雾、雪花、火花、流光、碎片、花瓣、音符等全部粒子层 | 声明式 emitter（拖尾/湍流/重力/碰撞力场）、实例化级性能、独立于 three 小版本 |
| `postprocessing`（pmndrs） | ^6.39.4 | **电影级后处理链**：GodRays、Bloom、SSAO、DepthOfField、ChromaticAberration、Vignette、SMAA、LUT/色彩分级、胶片颗粒 | three.js 生态事实标准，pass 即插即用；替代手写复合的 EffectComposer 栈 |
| `three-good-godrays` | ^0.12 | 屏幕空间 raymarch 体积光（黑洞透镜、爆炸闪光、闪电氛围、烟花光柱） | 为 postprocessing 编写，直接复用；GodRaysEffect 效果不足时启用 |
| `cannon-es` | ^0.20 | 刚体物理：玻璃碎片、弹片、碎石、弹壳的真实碰撞/重力/反弹 | 轻量纯 JS、与 three 无缝、测试可 mock |

**"禁止自研"边界原则**：引擎级能力（粒子系统、后处理、物理、体积光）全部由上表专业库承担；逐素材的"特效配方"（Stage 编排 + ShaderMaterial 材质 + GPUComputationRenderer 模拟场）属于 Three.js 公开编程接口上的组合描述，与行业 CG 制作方式一致，不构成自研引擎。写入 ADR（`docs/adr/2026-08-28-cg-effects-stack.md`）作为宪法记录。

## 3. 性能策略（已确认：无固定 fps，最流畅优先）

### 3.1 五档画质（用户可自选）

| 档位 | 粒子乘数 | 后处理栈 | 体积/光追层 | 物理刚体 | pixelRatio 上限 |
|---|---|---|---|---|---|
| 电影级 | 1.00× | 全链（GodRays+Bloom+SSAO+色散+颗粒+SMAA+Vignette+LUT） | 全开 | 全量 | 2.0 |
| 高 | 0.75× | Bloom+色散+颗粒+SMAA | 上帝光开，SSAO 关 | 全量 | 1.75 |
| 中 | 0.50× | Bloom+SMAA | 关 | 减半 | 1.5 |
| 低 | 0.30× | SMAA 仅 | 关 | 无 | 1.25 |
| 自动 | 见 3.2 | 见 3.2 | 见 3.2 | 见 3.2 | 见 3.2 |

- **档位 = 画质目标**，不承诺任何 fps 数值。
- 每档同时作用于：`ThreeEffectRenderer` 分辨率、`CinematicRenderPipeline` pass 列表、粒子 emitter 数量/上限、物理 step 频率与刚体数、全屏场 shader 迭代次数。
- 自动档降级/升级全部在特效边界（`cancel`/`start`）实施，不打断进行中的特效。

### 3.2 自动档 = 运行时自适应

- **初始档**：首次特效启动前的能力探测（WebGL 上下文报告 + 5 秒空闲帧采样基准），映射到 中/高/电影 三档之一。
- **运行中**：维护 30 帧滚动窗口，窗口平均帧耗时超过"本机基准 × 1.6"持续 2 个连续窗口 → 降一档；窗口帧耗时持续低于"基准 × 0.7" 连续 6 个窗口 → 升一档。
- 阈值全部相对于**本机运行时基准**而非绝对值，因此"最流畅"在所有设备上成立；低/高两端封顶不外溢。
- 手动档位（电影/高/中/低）优先于自动降档，用户选择即锁定。

### 3.3 新增指标（替代固定 fps 断言）

- 帧耗时采样 P50/P95（性能测压脚本，`vitest bench` 或独立 harness）。
- 掉档事件计数（开发日志）。
- WebGL1 兼容：能力探测降级（`OES_standard_derivatives` 缺失时关闭 SSAO/色散等 GLSL 扩展依赖），保证 WebGL1 核显仍可跑低中档。
- WebGL 不可用 → 现有 2D canvas 降级链（不动）。

## 4. CG 特效架构

### 4.1 架构（独立场景注册表）

```
crack 触发（packId × preset × params）
 └─ CgSceneRegistry：以 packId 为键查找专属场景（42 内置素材 → 42 个独立场景）
      └─ CgStage 编排器（每素材独立 Stage：入场 → 主幕 → 多元素互动 → 消隐）
           ├─ 粒子层    three.quarks（每场景 5~10 个 emitter，全部素材专属）
           ├─ 体积层    postprocessing GodRays / three-good-godrays / 屏幕空间 raymarch
           ├─ 刚体层    cannon-es（碎片/弹片/玻璃屑，每场景独立的 body 配置）
           ├─ 环境场面  ShaderMaterial（乌云 FBM、吸积盘、龙卷漏斗、水面、星云…）
           ├─ 结构网格  程序化 mesh（凤凰躯干、琴键、唱片、盾牌…）
           └─ 全屏场    现有 FullFieldSpectacleLayer 扩展（每场景参数化）
 └─ 后处理链           postprocessing（按档位装配）
    ↓ 特效结束
 清场 → 现有 runId/dispose 资源生命周期（不动）
```

**独立性规则（用户硬性要求）**：

1. **场景键是 packId**：42 个内置素材 → 42 个 `CgScene` 注册项，一一对应、互不共享场景构成。preset（如 `dash` 被 katana/bow/spear 共用）仅提供 `PhysicalProfile`（物理档案+族分派），不再决定场景内容——三个素材虽同用 dash 物理，但分别是"居合斩/一箭穿云/破空长矛"三个完全不同的场景。
2. **共享仅限工具层**：emitter 工厂、噪声纹理、cannon world、后处理装配函数可以复用；**共享工具不得导出成品场景**。
3. 用户自定义包沿用现有 preset 通用 Stage（`renderContractFor` 语义不变），不受影响。
4. 低档位回退现有程序化 Stage（`legacy` 路径保留，不动）；中高档才创建 CG 场景 —— 保证动画/音效/宏发送在任何档位都能工作。
5. 42 个场景注册表 = 42 个唯一键，测试断言无缺漏、无重复。

### 4.2 42 素材独立 CG 场景设计

> 每个场景：**场景概念**（1 句世界观）→ **元素清单**（构成件，注明技术载体）→ **多元素互动**（场景内元素的相互作用）→ **三幕编排**（毫秒，基于 `effect-timings`）→ **全屏覆盖** → **独立签名**（其它素材不具备的唯一机制）。物理参数（surface/force/mass/restitution/friction/drag/gravity）均取自 `material-identity.ts` 对应素材行，驱动运动复杂度与趣味性。

#### 场景 01 rocket（jet · 发射升空，时长 1200ms）

- **概念**：深夜航天发射场，一枚火箭点火升空，尾焰照亮整个画面上半屏。
- **元素**：①引擎主焰（quarks 锥形 emitter，蓝核+白边双层）②尾烟两侧（quarks 灰烟，升速递减+体积膨胀）③发射台结构网格（4 根立柱+平台，闪白消隐）④音爆环（双环 mesh，依次扩散）⑤燃料碎屑（cannon 小球刚体，落台弹跳）⑥地平线光带 shader（晨曦线）⑦背景星点阵（instanced 光点+轻微闪烁）⑧二级点火亮斑（point light 脉冲）。
- **互动**：主焰熄灭瞬间音爆环从锥底扩散并推开两侧烟柱形成蘑菇帽；碎屑被音爆环扫动改变轨迹；地平线光带随引擎亮度整体增辉。
- **三幕**：0–240ms 点火抖动（发射台颤动+烟慢升）；240–900ms 升空（尾焰拉长、发射台闪白退出）；900–1200ms 二级点火+音爆环+星屑散尽。
- **全屏**：尾焰光柱自下而上贯穿中轴线，烟柱铺满下半屏。
- **签名**：唯一自下而上"发射"构图的素材；发射台消隐只此一例。

#### 场景 02 phoenix（rise · 浴火重生，1200ms）

- **概念**：苍茫高空，凤凰展翅盘旋后爆燃成漫天金羽。
- **元素**：①双翼火羽（quarks 沿翼形轨迹）②凤凰躯干（低多边形 mesh，发光材质）③头顶火焰冠（小 emitter 高频抖动）④金羽雨（quarks 旋转渐落，余烬托浮）⑤涅槃光柱（godray 向上）⑥热浪扭曲层（屏幕空间折射 shader）⑦云层撕裂（FBM 云被热浪推开）⑧冲击羽环形波（双层环）。
- **互动**：火羽在翼尖汇聚成羽；金羽下落半程被余烬推升一次（重力反转短促）；光柱在爆燃瞬间照亮云层。
- **三幕**：0–250ms 展翅亮翼；250–800ms 盘旋+火羽拖迹+云层撕裂；800–1200ms 爆燃成金雨、光柱退场。
- **全屏**：双翼展开横贯 2/3 屏宽，金雨覆盖全屏。
- **签名**：唯一"对称双翼+涅槃金雨"；热浪折射屏幕效果全库唯一。

#### 场景 03 lightning（bolt · 雷暴云幕，1200ms）

- **概念**：乌云压顶，三道先导在云内酝酿后劈落，天地间电弧四起。
- **元素**：①雷暴乌云（全屏 FBM 云 shader，内部闪电频闪）②三相先导电弧（主弧+双分叉，quarks 火花节点）③云内暗闪（体积光频闪）④落雷点地面亮斑（光池扩散）⑤雨幕（quarks 斜雨，被电弧照亮变白）⑥电弧余波（屏缘游走电蛇，细线 shader）⑦雷声光暴（整屏白光脉冲×2）⑧云缘电荷游灯（instanced 小球，云缘放电点）。
- **互动**：雨幕在电弧经过处瞬间增亮；云内暗闪节奏与主弧劈落耦合（先闪一次天、再劈一道）；落雷点亮斑启动光池涟漪并溅起雨滴。
- **三幕**：0–240ms 云压+云内暗闪蓄能；240–780ms 三相电弧依次劈落+落雷点光池；780–1200ms 余电游走+云层散场。
- **全屏**：乌云铺满全屏顶部 2/3，电弧贯穿，落雷点光池覆盖落点全屏半径。
- **签名**：唯一"天象"级场景；先导-暗闪-落雷三相耦合全库唯一。

#### 场景 04 dragon（wave · 腾龙戏珠，1200ms）

- **概念**：云海翻腾，一条龙自云雾中破出，缠绕一颗光珠。
- **元素**：①龙身（骨骼链 mesh，12~16 节，正弦波蜿蜒）②鳞光（quarks 沿龙身表面流窜）③龙爪扰动云（FBM 云被龙身挤出空隙）④光珠（核心发光球+光晕）⑤龙珠互绕（双环轨道）⑥雨丝背景（稀疏斜雨）⑦龙息（一次喷吐火团 emitter）⑧雾境（体积雾层）。
- **互动**：龙身缠绕光珠时珠光沿鳞片流走；龙息推散云层；珠轨随龙身摆幅摆动。
- **三幕**：0–300ms 云破龙现；300–900ms 蜿蜒缠珠+龙息；900–1200ms 龙腾入云、珠光余晖。
- **全屏**：龙身蜿蜒横穿全屏对角线；云海铺底。
- **签名**：唯一"生物链+缠绕"场景；骨骼链 mesh 全库唯一。

#### 场景 05 ninja-star（orbit · 回旋手里剑，1200ms）

- **概念**：深夜月下，一枚手里剑旋飞而出，绕场回旋后消失。
- **元素**：①手里剑本体（星形 mesh 高速自旋）②残影环（5 层 ghost 半透明层）③金属反光扫掠（镜面高光带）④回旋轨迹光带（quarks 沿椭圆轨道）⑤月轮（满月 shader + 月晕）⑥落地火星（cannon 小碎片弹跳）⑦屏边冲击纹（细线环）⑧风切声纹（贴近轨迹的细线）。
- **互动**：轨迹光带与残影在回旋切点汇合；火星从切点崩出；月轮被剑影瞬间遮暗。
- **三幕**：0–300ms 掷出+自旋加速；300–900ms 回旋切点×2+火星；900–1200ms 急停回收+残影衰减。
- **全屏**：回旋椭圆横跨全屏。
- **签名**：唯一"回旋镖式"运动曲线；ghost 残影 5 层全库唯一。

#### 场景 06 katana（dash · 居合斩，1200ms）

- **概念**：万籁俱寂，一道刀光划破黑暗——拔刀一击。
- **元素**：①刀身（反光斜面 mesh + 刀刃高光带）②斩击线（亮白细线+两侧辉光）③刀气弧（弧形冲击波）④斩击火花（quarks 定向喷射）⑤残影人间（3 层 ghost 定格）⑥屏裂闪光（玻璃裂纹式白光）⑦绸布飘落（cloth 约束网格，被刀风撩起）⑧月光静场（背景暗场+月晕）。
- **互动**：刀气弧扫过绸布将其截断；火花沿斩击线飞溅；屏裂闪光在斩击瞬间全屏闪白。
- **三幕**：0–200ms 静场蓄势；200–700ms 一斩（线+弧+火花同帧爆发）；700–1200ms 刀身入鞘暗光+残影散。
- **全屏**：斩击线横贯全屏对角线。
- **签名**：唯一"居合一击"叙事；静场→爆发对比全库最强烈。

#### 场景 07 crystal（shatter · 水晶碎玉，1200ms）

- **概念**：一座水晶尖塔被击中，沿晶面崩解成漫天晶屑与棱光。

#### 场景 42 black-hole（singularity · 吞噬黑洞，1850ms）

- **概念**：黑洞悬于星空，吸积盘旋转，一切被引力扯入事件视界。
- **元素**：①事件视界（黑球+光子环 shader）②吸积盘（quarks 双旋涡 GPU 粒子 + 轨道碎片）③被吞噬尘埃（quarks 沿螺旋线向心加速）④引力透镜（后处理 GodRays 环绕扭曲）⑤双极相对论喷流（quarks 双向卷流：亮芯+线框鞘）⑥背景星场（shader 星被拉伸）⑦吸积温度渐变（内白外橙、蓝紫过渡）⑧临界闪现（尘埃越过临界线闪紫）⑨尾声白炽（奇点熄灭白闪）。
- **互动**：尘埃入盘前被加速、过临界线闪紫、部分被喷流"弹回"；透镜在尘埃密集处最强；背景星在吸积盘附近被拉伸弯曲。
- **三幕**：0–450ms 视界稳定+盘成形；450–1450ms 吞噬+喷流+透镜最强；1450–1850ms 白炽熄灭。
- **全屏**：盘直径占全屏 2/3，透镜扭曲覆盖四缘。
- **签名**：唯一"引力主场"（全屏被弯曲）；吞噬+喷流回弹循环（唯一有"物质回弹"的吸积机制）。

> **独立性自检**：42 个场景不存在"甲=乙核心"的复用；共享 preset 物理的素材（katana/bow/spear、harp/lotus、guitar/pulse、meteor/comet 等）均设计了完全不同的场景机制与元素组合。每场景列出的"独立签名"即独立性判据，实现与测试逐条核查。

## 7. 测试与验收

### 7.1 单元/契约（Vitest + cargo test，沿用现有规则）

- `quality` schema 边界（非法值拒绝、默认值、迁移）。
- 每素材 CG Stage 的**纯逻辑部分**（三幕时间映射、粒子参数推导、物理签名输入）单测。
- **场景注册表**：42 个 `BUILTIN_PACK_IDS` → 42 个 `CgScene` 一一对应（无缺漏、无重复键）；每个场景的"独立签名"元素逐条断言存在；同 preset 的素材（如 dash×3）断言场景类互不相同。
- 后处理链组装函数：按档位返回 pass 列表（断言各档 pass 集合）。
- 自动降档控制器：模拟帧耗时序列 → 断言升/降档事件（纯函数化，可注入 fake 帧数据）。
- cannon-es 物理层：以 mock 刚体验证接口（不依赖真实 WebGL）。
- 2D 降级：WebGL 不可用/损坏时 stage 返回值断言（沿用现有测试）。

### 7.2 视觉验收（每批）

- 生成 42 素材特效预览页（静态 HTML → Artifact），逐素材目视对比设计预期。
- 图标 42 枚并排预览 → 统一风格目视验收。
- 亮/暗主题、自动/高/中/低档截图对比。

### 7.3 回归

- `npm run ci`（typecheck + vitest + cargo clippy -D warnings + cargo test）全绿。
- E2E 10 条核心用户旅程不回归（尤其"覆盖层甩动→crack→宏发送"链路）。
- WebGL 1 环境（软件渲染 / 旧核显）走降级验证。
- 性能：帧耗时 P50/P95 采样报告，无固定 fps 断言。

## 9. 风险与边界

- **不触碰**：声音引擎（Web Audio）、宏发送（enigo）、Tauri 窗口/托盘/快捷键、`src-tauri/materials/`（v2 遗留）、`src-tauri/packs/*/pack.json` 结构、2D 降级链实现。
- **性能**：画质上限由用户档位决定，自动档以"本机基准"自适应；特效总时长不变（沿用 `effect-timings`）。
- **兼容性**：WebGL1/2 能力探测；`three.quarks`、`postprocessing`、`three-good-godrays`、`cannon-es` 与 three 0.185 的 peer 版本在 M0 冒烟验证；若不兼容则钉三库版本或替换等价库（记录于 ADR）。
- **图标**：仅内置 42 枚重绘；用户自定义包图标不动。
- **文档约束**：本设计文档为 `docs/superpowers/specs/` 新增，不改动既有规格文档。
