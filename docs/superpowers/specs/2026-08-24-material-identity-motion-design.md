# 素材身份与局部动效升级设计

## 目标

提升素材的精致感、纹理辨识度和互动叙事，重点解决左轮手枪与神龙的素材关联不足，同时收敛不属于素材本体的全屏背景光效。现有工作区中已经完成的斧、轮刃、龙卷风和图标改动全部保留。

## 设计决策

### 左轮手枪

左轮使用明确的四段时间线：

1. 0-0.12：枪身滑屏后定位，枪口压缩并产生短促火焰核心。
2. 0.12-0.48：枪口焰熄灭，单颗金属子弹沿枪口方向飞行，带有细曳光和逐渐收窄的弹道。
3. 0.25-0.62：弹壳从弹巢侧面抛出，旋转和抛物线独立于子弹。
4. 0.58-0.92：子弹在远端命中，出现局部命中火花、碎屑和一圈小型冲击环。

枪体增加枪管内膛、弹巢槽、握把防滑纹理和金属高光，不使用整屏闪光表达枪击。

### 神龙

神龙 WebGL 舞台由分节龙身、头部、角、须、背脊、鳞片和龙珠组成。每个分节保持独立材质和深度，运动时沿 S 型路径传递波峰；头部带有眼睛、口部和龙息喷口，龙珠沿龙头前方的偏移轨迹跟随。鳞片贴着分节闪烁并在尾部脱落，背脊随曲率翻转，龙息只从口部射向前方。Canvas 降级路径同步使用鳞片、龙息、龙珠和爪痕局部粒子。

### 共用层

`FullFieldSpectacleLayer` 不再对所有素材默认渲染覆盖到视口边缘的场和全屏冲击环。局部素材舞台负责主体叙事；共用层仅保留低透明度、短半径、与材质方向一致的辅助粒子。全屏场只对明确需要空间尺度的预设保留，并通过局部半径参数限制 alpha 和 reach。

## 约束与验证

- 保持 Three.js 的现有 `FamilyContext` / `FamilyLayer` 接口。
- 单次素材爆裂粒子总数不超过现有 180 上限。
- 所有动态对象使用稳定名称，便于单元测试观察局部运动。
- 纹理 SVG 保持 512x512 viewBox、安全边距和至少 1px 的小尺寸可见细节。
- 支持 WebGL 失败时的 Canvas 降级。

## 验收标准

- 左轮测试可观察到枪口火焰、子弹飞行、弹壳抛物线和远端命中四个阶段。
- 神龙测试可观察到头部领先、龙身波峰传递、鳞片相对分节附着、龙珠跟随和龙息方向。
- 共用层在局部素材预设中不再把光效扩展到视口边缘。
- `pnpm typecheck`、相关 Vitest 测试和 `pnpm build` 通过。
