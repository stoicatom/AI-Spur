# 资源优化指南

## 音频资源

当前音效文件：5 个 MP3，总大小 ~260KB

### 规格
- **格式**: MP3
- **码率**: 192 kbps
- **采样率**: 48 kHz
- **声道**: Stereo

### 优化建议

对于短促音效（鞭子声），可以降低参数而不影响听感：
- **码率**: 96 kbps（减少 50%）
- **采样率**: 44.1 kHz（标准 CD 质量）
- **声道**: Mono（鞭子音效无空间感需求）

预期压缩：260KB → ~130KB（减少 50%）

### 使用优化脚本

```bash
# 预览优化效果（生成到 sounds-optimized/）
pnpm run optimize:audio

# 检查优化后的音质
open sounds-optimized/A.mp3

# 如果满意，替换原文件
rm -rf sounds && mv sounds-optimized sounds

# 提交
git add sounds && git commit -m "perf: 优化音效文件体积"
```

### 当前状态

- **内存占用**: 音频预加载到 `<audio>` 元素

| 操作 | 节省 | 影响 |

## 自定义资源

- **格式限制**: MP3, OGG, WAV

### 用户上传皮肤纹理（P4.3 计划）
